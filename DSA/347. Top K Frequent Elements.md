```python
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:

        hashmap = {}
        final_arr = []
        

        for i in nums:
            hashmap[i] = hashmap.get(i,0) + 1

        heap = []
        
        for elem, freq in hashmap.items():
            heapq.heappush(heap,(freq,elem))
            if len(heap) > k:
                heapq.heappop(heap)

        for freq, elem in heap:
            final_arr.append(elem)        
        
        return final_arr
```

# TOP K FREQUENT ELEMENTS - #347

## PROBLEM -

the problem is that we are given an array and an integer `k`.

we have to find the `k` elements that appear the most number of times in the array.

for example:

```text
nums = [1,1,1,2,2,3]
k = 2
```

frequency of each element:

```text
1 -> 3 times
2 -> 2 times
3 -> 1 time
```

so the top `2` frequent elements are:

```text
[1,2]
```

we don't need to return them in any particular order.

---

# APPROACH -

we are using **hashmap + min heap** here.

first, we use a hashmap to count how many times each element appears.

then we use a **min heap** to keep only the top `k` frequent elements.

the main idea is:

```text
hashmap -> count frequency
heap -> keep top k frequencies
```

---

# CODE EXPLANATION -

## 1. CREATE HASHMAP

```python
hashmap = {}
final_arr = []
```

`hashmap` will store:

```text
element -> frequency
```

for example:

```text
nums = [1,1,1,2,2,3]

hashmap = {
    1: 3,
    2: 2,
    3: 1
}
```

`final_arr` will finally store our answer.

---

# 2. COUNT FREQUENCY

```python
for i in nums:
    hashmap[i] = hashmap.get(i,0) + 1
```

we go through every element in `nums`.

this part:

```python
hashmap.get(i, 0)
```

means:

* if `i` already exists in the hashmap, get its current frequency
* if it doesn't exist, return `0`

then we add `1`.

for example:

```text
nums = [1,1,1,2,2,3]
```

first `1`:

```text
hashmap[1] = 0 + 1
          = 1
```

second `1`:

```text
hashmap[1] = 1 + 1
          = 2
```

third `1`:

```text
hashmap[1] = 2 + 1
          = 3
```

finally:

```text
{
    1: 3,
    2: 2,
    3: 1
}
```

---

# 3. CREATE MIN HEAP

```python
heap = []
```

in Python, `heapq` gives us a **min heap**.

this means the smallest element is always at the top.

here we are storing:

```python
(freq, elem)
```

so the heap primarily compares the **frequency**.

for example:

```text
(freq, elem)

(3, 1)
(2, 2)
(1, 3)
```

the smallest frequency will stay at the top.

---

# 4. ADD ELEMENTS TO HEAP

```python
for elem, freq in hashmap.items():
    heapq.heappush(heap,(freq,elem))
```

we go through every element and its frequency.

for example:

```text
elem = 1
freq = 3
```

we push:

```python
(3, 1)
```

another example:

```text
elem = 2
freq = 2
```

we push:

```python
(2, 2)
```

so the heap contains frequency along with the element.

---

# 5. KEEP ONLY K ELEMENTS

```python
if len(heap) > k:
    heapq.heappop(heap)
```

this is the main part of the solution.

suppose:

```text
k = 2
```

we only want the top `2` frequent elements.

so whenever the heap size becomes greater than `k`, we remove the smallest-frequency element.

for example:

```text
heap:

(1,3)
(2,2)
(3,1)
```

there are `3` elements but we only need `2`.

because this is a **min heap**, `heappop()` removes:

```text
(1,3)
```

because frequency `1` is the smallest.

now the heap contains:

```text
(2,2)
(3,1)
```

these are the top `2` frequent elements.

---

# WHY MIN HEAP?

this might look confusing because we want the **most frequent** elements, but we are using a **min heap**.

the reason is that we want the smallest frequency among our current top `k` elements to be easy to remove.

so:

```text
min heap
   ↓
smallest frequency is at top
   ↓
if size > k
   ↓
remove smallest
```

this allows us to maintain only `k` elements in the heap.

---

# 6. CREATE FINAL ARRAY

```python
for freq, elem in heap:
    final_arr.append(elem)
```

our heap contains tuples like:

```text
(freq, elem)
```

but we only need the elements.

so:

```python
final_arr.append(elem)
```

adds only the element to the final answer.

for example:

```text
heap = [(2,2), (3,1)]
```

we take:

```text
2
1
```

so:

```text
final_arr = [2,1]
```

the order doesn't matter in this problem.

---

# 7. RETURN ANSWER

```python
return final_arr
```

finally, we return the `k` most frequent elements.

---

# COMPLETE FLOW -

for:

```text
nums = [1,1,1,2,2,3]
k = 2
```

first count frequencies:

```text
1 -> 3
2 -> 2
3 -> 1
```

then push into min heap:

```text
(3,1)
(2,2)
(1,3)
```

when heap size becomes greater than `2`, remove the smallest:

```text
(1,3) -> removed
```

remaining:

```text
(2,2)
(3,1)
```

answer:

```text
[2,1]
```

# IMPORTANT POINTS -

### `hashmap`

used for counting frequency:

```text
element -> frequency
```

### `heapq`

Python's `heapq` implements a **min heap**.

### `(freq, elem)`

we store frequency first because we want the heap to compare frequencies first.

```python
heapq.heappush(heap, (freq, elem))
```

### why `len(heap) > k`?

because we want the heap to contain **at most `k` elements**.

when it becomes larger than `k`, remove the smallest frequency.

### why not use a max heap?

we could, but then we would potentially keep all elements in the heap.

with this approach, the heap only contains `k` elements, making it more efficient when `k` is small compared to `n`.

---

# TIME COMPLEXITY -

counting frequencies:

```text
O(n)
```

where `n` is the number of elements in `nums`.

then we process `m` unique elements using the heap:

```text
O(m log k)
```

where `m` is the number of unique elements.

overall:

```text
O(n + m log k)
```

and since `m <= n`, this is commonly written as:

```text
O(n log k)
```

---

# SPACE COMPLEXITY -

the hashmap can contain all unique elements:

```text
O(n)
```

the heap contains at most `k` elements:

```text
O(k)
```

so overall:

```text
O(n + k)
```

which is usually simplified to:

```text
O(n)
```

---

# FINAL IDEA -

remember the solution like this:

```text
1. hashmap -> count every element
2. min heap -> store (frequency, element)
3. if heap size > k -> remove smallest frequency
4. remaining elements -> top k frequent elements
```

the important trick is:

```text
min heap + size k
```

we use a min heap because we want to quickly remove the **least frequent element** whenever we have more than `k` elements.
