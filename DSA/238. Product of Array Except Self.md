```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        result = [1] * len(nums)
        
        left_product = 1
        right_product = 1
        
        for i in range(len(nums)):
            result[i] = left_product
            left_product *= nums[i]
            
        for i in range(len(nums)-1,-1,-1):
            result[i] *= right_product
            right_product *= nums[i]
           
        return result
```

# PRODUCT OF ARRAY EXCEPT SELF - #238

## PROBLEM -

we are given an array `nums`.

for every index, we have to return the product of **all the elements except the element at that index**.

for example:

```text
nums = [1,2,3,4]

output = [24,12,8,6]
```

because:

```text
index 0 -> 2 * 3 * 4 = 24
index 1 -> 1 * 3 * 4 = 12
index 2 -> 1 * 2 * 4 = 8
index 3 -> 1 * 2 * 3 = 6
```

we also need to solve it **without using division**.

---

# APPROACH -

we are using **two passes** here.

for every index, we need:

```text
product of everything on the left
+
product of everything on the right
```

so the idea is:

```text
left product  -> everything before current index
right product -> everything after current index
```

then:

```text
answer = left product * right product
```

we store the left product directly inside `result`, and then multiply it by the right product during the second loop.

---

# CODE EXPLANATION -

## 1. CREATE RESULT ARRAY

```python
result = [1] * len(nums)
```

we create an array of the same length as `nums`.

for example:

```text
nums = [1,2,3,4]

result = [1,1,1,1]
```

we start with `1` because multiplication by `1` does not change the value.

---

# 2. CREATE LEFT AND RIGHT PRODUCTS

```python
left_product = 1
right_product = 1
```

these two variables keep track of the product.

`left_product`:

```text
product of elements before current index
```

`right_product`:

```text
product of elements after current index
```

we start both with `1` because there is no element before the first index or after the last index.

---

# 3. FIRST LOOP - LEFT PRODUCT

```python
for i in range(len(nums)):
    result[i] = left_product
    left_product *= nums[i]
```

we move from **left to right**.

the important thing is:

```python
result[i] = left_product
```

we first store the product of everything **before** `i`.

then:

```python
left_product *= nums[i]
```

we include the current element for the next index.

---

## EXAMPLE

```text
nums = [1,2,3,4]
```

initially:

```text
left_product = 1
result = [1,1,1,1]
```

### i = 0

```text
result[0] = 1
```

there is nothing before index `0`.

then:

```text
left_product = 1 * 1
             = 1
```

result:

```text
[1,1,1,1]
```

---

### i = 1

```text
result[1] = 1
```

everything before index `1` is:

```text
1
```

then:

```text
left_product = 1 * 2
             = 2
```

---

### i = 2

```text
result[2] = 2
```

everything before index `2` is:

```text
1 * 2 = 2
```

then:

```text
left_product = 2 * 3
             = 6
```

---

### i = 3

```text
result[3] = 6
```

everything before index `3` is:

```text
1 * 2 * 3 = 6
```

then:

```text
left_product = 6 * 4
             = 24
```

after the first loop:

```text
result = [1,1,2,6]
```

this currently contains only the **left products**.

---

# 4. SECOND LOOP - RIGHT PRODUCT

now we move from **right to left**.

```python
for i in range(len(nums)-1,-1,-1):
```

this means:

```text
start -> last index
stop  -> -1
step  -> -1
```

for:

```text
nums = [1,2,3,4]
```

the indexes will be:

```text
3 -> 2 -> 1 -> 0
```

---

# 5. MULTIPLY WITH RIGHT PRODUCT

```python
result[i] *= right_product
```

we already have the left product stored in `result[i]`.

now we multiply it with the product of everything on the right.

so:

```text
result[i] =
left product * right product
```

then:

```python
right_product *= nums[i]
```

we include the current element so that it can be used for the next index.

---

## EXAMPLE

before the second loop:

```text
nums   = [1,2,3,4]
result = [1,1,2,6]
```

and:

```text
right_product = 1
```

### i = 3

```text
result[3] = 6 * 1
          = 6
```

then:

```text
right_product = 1 * 4
              = 4
```

---

### i = 2

```text
result[2] = 2 * 4
          = 8
```

then:

```text
right_product = 4 * 3
              = 12
```

---

### i = 1

```text
result[1] = 1 * 12
          = 12
```

then:

```text
right_product = 12 * 2
              = 24
```

---

### i = 0

```text
result[0] = 1 * 24
          = 24
```

final:

```text
result = [24,12,8,6]
```

---

# WHY DOES THIS WORK?

for every index, we basically calculate:

```text
             current
                ↓
[  left  ] [ nums[i] ] [  right  ]
```

we don't include `nums[i]`.

instead:

```text
result[i] = left product * right product
```

for example, at index `2`:

```text
[1,2] [3] [4]
```

left product:

```text
1 * 2 = 2
```

right product:

```text
4
```

so:

```text
2 * 4 = 8
```

which is the required answer.

---

# IMPORTANT PART

the order in the first loop is important:

```python
result[i] = left_product
left_product *= nums[i]
```

we store the current left product **before** multiplying by `nums[i]`.

otherwise the current element would also be included, which we don't want.

same thing in the second loop:

```python
result[i] *= right_product
right_product *= nums[i]
```

first use the right product, then add the current element to it for the next index.

---

# WHY NOT USE DIVISION?

a common approach would be:

```text
total product / nums[i]
```

but the problem does not allow division.

also, division creates problems when the array contains `0`.

this left + right product approach works correctly even when there are zeros.

for example:

```text
nums = [1,2,0,4]
```

the algorithm still works without any special zero handling.

---

# TIME COMPLEXITY -

we go through the array twice:

```text
first loop  -> O(n)
second loop -> O(n)
```

so overall:

```text
O(n)
```

---

# SPACE COMPLEXITY -

we use the `result` array for the answer.

apart from the output array, we only use:

```text
left_product
right_product
```

so the **extra space** is:

```text
O(1)
```

and the output array itself takes:

```text
O(n)
```

so when discussing auxiliary space, we say:

```text
O(1) extra space
```

---

# FINAL IDEA -

remember it like this:

```text
1. go left -> right
   store left product

2. go right -> left
   multiply with right product
```

or:

```text
result[i] = left product × right product
```

the main trick is that we don't need separate left and right arrays.

we reuse the `result` array to store the left products first, and then update it with the right products.
