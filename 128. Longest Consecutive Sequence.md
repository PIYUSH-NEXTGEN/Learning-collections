```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        best = 0

        for n in num_set:
            if n - 1 not in num_set:
                cur = n
                length = 1
                while cur + 1 in num_set:
                    cur += 1
                    length += 1
                best = max(best, length)

        return best
```

# LONGEST CONSECUTIVE SEQUENCE - #128

## PROBLEM -

we are given an unsorted array of numbers.

we have to find the length of the **longest consecutive sequence**.

for example:

```text
nums = [100,4,200,1,3,2]
```

the consecutive sequences are:

```text
[1,2,3,4] -> length = 4

[100] -> length = 1

[200] -> length = 1
```

so the answer is:

```text
4
```

the important thing is that the numbers do **not** need to be next to each other in the original array.

---

# APPROACH -

we are using a **set** here.

a set allows us to check whether a number exists in approximately `O(1)` time.

first we convert the array into a set:

```python
num_set = set(nums)
```

then for every number, we check:

```text
is the previous number present?
```

if:

```text
n - 1 not in num_set
```

then `n` is the **starting point** of a consecutive sequence.

from there, we keep checking:

```text
n + 1
n + 2
n + 3
...
```

until the sequence ends.

---

# CODE EXPLANATION -

## 1. CREATE A SET

```python
num_set = set(nums)
```

we convert the array into a set.

for example:

```text
nums = [100,4,200,1,3,2]

num_set = {100,4,200,1,3,2}
```

the main reason for using a set is fast lookup.

for example:

```python
if 5 in num_set:
```

we can quickly check whether `5` exists.

also, duplicates are automatically removed.

for example:

```text
nums = [1,2,2,3]

set(nums) = {1,2,3}
```

---

## 2. STORE THE BEST ANSWER

```python
best = 0
```

`best` stores the longest consecutive sequence we have found so far.

initially:

```text
best = 0
```

---

# 3. LOOP THROUGH THE SET

```python
for n in num_set:
```

we check every unique number in the set.

for example:

```text
num_set = {100,4,200,1,3,2}
```

we check each number one by one.

---

# 4. FIND THE STARTING POINT

```python
if n - 1 not in num_set:
```

this is the most important part of the solution.

we check whether the number before `n` exists.

for example:

```text
n = 3
```

we check:

```text
3 - 1 = 2
```

and `2` exists.

so `3` is **not** the beginning of the sequence.

but:

```text
n = 1
```

we check:

```text
1 - 1 = 0
```

and `0` does not exist.

so `1` is the beginning of:

```text
1 -> 2 -> 3 -> 4
```

this condition makes sure that we only start counting from the beginning of a sequence.

---

# 5. START THE SEQUENCE

```python
cur = n
length = 1
```

if `n` is the starting number, we create:

```text
cur
```

to keep track of the current number.

and:

```text
length
```

to keep track of the length of the sequence.

for example:

```text
n = 1

cur = 1
length = 1
```

currently we have:

```text
[1]
```

so length is `1`.

---

# 6. CHECK THE NEXT NUMBER

```python
while cur + 1 in num_set:
```

now we check whether the next consecutive number exists.

for:

```text
cur = 1
```

we check:

```text
1 + 1 = 2
```

if `2` exists, the sequence continues.

---

## MOVE TO THE NEXT NUMBER

```python
cur += 1
```

if the next number exists, we move `cur` to that number.

for example:

```text
cur = 1

cur += 1

cur = 2
```

---

## INCREASE LENGTH

```python
length += 1
```

because we found another consecutive number.

so:

```text
[1]

length = 1
```

then:

```text
[1,2]

length = 2
```

then:

```text
[1,2,3]

length = 3
```

then:

```text
[1,2,3,4]

length = 4
```

when `5` is not found, the loop stops.

---

# 7. UPDATE BEST

```python
best = max(best, length)
```

after finding one complete sequence, we compare its length with our previous best.

for example:

```text
best = 3
length = 4
```

then:

```text
best = max(3,4)
```

so:

```text
best = 4
```

if we find another sequence with length `2`:

```text
best = max(4,2)
```

so `best` remains:

```text
4
```

---

# 8. RETURN ANSWER

```python
return best
```

after checking all the numbers, `best` contains the longest consecutive sequence length.

---


set:

```text

```

consider:

```text

```

check:

```text
1 - 1 = 0
```

`0` does not exist.

so `1` is the starting point.

now:

```text
1 -> 2 -> 3 -> 4
```

```text
4
```

so:

```text

```

---

now consider:

```text

```

```text
2 - 1 = 1
```

```text
3
```

```text

```

```text
99 not in num_set
```



```text

```

# WHY DO WE CHECK `n - 1`?

this is the main trick of the problem.

suppose:

```text
nums = [1,2,3,4]
```

if we started counting from every number:

```text
1 -> 2 -> 3 -> 4
2 -> 3 -> 4
3 -> 4
4
```

we would repeat a lot of work.

instead, we only start when:

```python
n - 1 not in num_set
```

so:

```text
1 -> start counting
2 -> don't start
3 -> don't start
4 -> don't start
```

this prevents unnecessary work.

---

# IMPORTANT POINTS -

### `set(nums)`

used for fast lookup:

```text
is this number present?
```

### `n - 1 not in num_set`

means:

```text
there is no previous number
```

therefore:

```text
n is the starting point
```

### `cur`

keeps track of the current number while building the sequence.

### `length`

keeps track of how many consecutive numbers we have found.

### `best`

stores the longest sequence found so far.

---

# TIME COMPLEXITY -

creating the set:

```text
O(n)
```

checking the numbers and building sequences:

```text
O(n)
```

so overall:

```text
O(n)
```

the important thing is that we don't start the `while` loop from every number.

we only start it from numbers that are the beginning of a sequence.

---

# SPACE COMPLEXITY -

we create a set containing the numbers:

```text
O(n)
```

so:

```text
O(n)
```

extra space.

---

# FINAL IDEA -

remember this problem like this:

```text
1. convert nums to set
2. check every number
3. if n - 1 does not exist -> n is the starting point
4. keep checking n + 1
5. count the sequence
6. update best
```

the main trick is:

```text
n - 1 not present
        ↓
start of sequence
        ↓
check n + 1, n + 2, n + 3...
```

this is what allows us to solve the problem in **O(n)** instead of sorting the array first.
